Women's Night-Travel Safety Intelligence

About the Project

This Business Intelligence project analyzes nighttime travel conditions using infrastructure, transport, and anonymized safety-related data.

Objectives

- Analyze streetlight functionality.
- Study nighttime public transport availability.
- Explore patterns in reported incidents.
- Visualize location-based information.
- Identify areas requiring further investigation.

Technologies

- Power BI
- Python
- SQL
- CSV datasets
- GitHub

Project Modules

1. Data Collection
2. Data Cleaning
3. Python Data Analysis
4. SQL Analysis
5. Power BI Dashboard
6. Insights and Recommendations

Dataset

Sample streetlight data is currently simulated for development and testing. Real-world conclusions will require verified datasets.

Expected Outcome

An interactive dashboard to explore nighttime travel conditions and identify potential infrastructure gaps.

Limitations

This project does not guarantee that any location is safe or unsafe. Results depend on the quality and completeness of the available data.
